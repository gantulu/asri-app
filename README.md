# ASRI APP

A responsive customer-facing storefront for ASRI Collection.

## Technology

- React + Vite + TypeScript
- Tailwind CSS
- Vitest + React Testing Library
- Playwright

## Requirements

- Node.js 22.12+
- npm 10+

## Getting started

```bash
npm install
npm run dev
```

## Available scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
npm run typecheck
npm run test
npm run test:e2e
```

## Project status

Phase 0 — Repository Foundation.

The implementation is intentionally limited to the approved foundation scope. Storefront features, Supabase integration, checkout, and payment workflows are not part of this phase.
